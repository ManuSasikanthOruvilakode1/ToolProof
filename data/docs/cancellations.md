# Cancellations

## Cancelling an order

Orders can be cancelled only while they are `pending` (not yet shipped). Cancellations are processed by the fulfilment team; customer care staff should pass the request on and tell the customer it will be confirmed by email.

## Refunds for cancelled orders

Payment is not captured for cancelled orders, so there is nothing to refund. Never issue a refund for an order with status `cancelled`.
