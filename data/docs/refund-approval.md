# Refund Approval and Escalation

## When approval is needed

Any refund over $200.00 must be approved by a supervisor. A refund of exactly $200.00 or less does not need approval.

## Approval codes

Supervisors issue approval codes in the format `APR-XXXX`. Each code is valid for one order only, up to a maximum amount, and can be used once. Customer care staff cannot look up or create approval codes.

## Without a code

Never guess or make up an approval code, and never split a large refund into smaller ones to stay under the limit. If no approval code has been provided, do not issue the refund. Tell the requester that the refund has been escalated for supervisor approval, or ask them for the approval code.
